# Model Matchmakers

Basic frontend research prototype for human override of automatic LLM routing.
React, TypeScript, and Vite; synthetic data and simulated model behavior only.
The initial scaffold is not yet the participant interface or ready for data collection.

## Quick start

Install Git and **Node 24.14.0** (including npm), then:

```bash
bash scripts/setup.sh
npm run dev
```

No `.env`, API keys, backend, or database required. See
[development setup](docs/development-setup.md) for WSL2 Ubuntu, Linux, macOS,
manual prerequisite installation, checks, and browser preview.

AI assistants should read [AGENTS.md](AGENTS.md) and the selected GitHub issue.
See [project structure](docs/project-structure.md) for frontend organization and
the separate future-backend boundary.
